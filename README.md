## 📚 Projetos

| Projeto | Disciplina | Descrição | Tecnologias |
|---|---|---|---|
| [💣 Campo Minado](campo-minado) | Algoritmos e Estruturas de Dados I (2024.2) | Jogo Campo Minado em C, evoluído em 3 entregas: da lógica básica até modularização, sistema de log e uma fila encadeada auxiliar. | `C` |

| [📊 Análise ENEM 2019](analise-enem-2019) | Ciência de Dados (2025.2) | Exploração dos microdados do ENEM 2019 e pipeline de machine learning para prever desempenho na redação, com comparação estatística de modelos e interpretabilidade via SHAP. | `Python`, `pandas`, `scikit-learn`, `SHAP` |
